# Repository guidance

Never push directly to `main`. Follow the [PR workflow](skills/poteto-mode/playbooks/opening-a-pr.md#opening-a-pr): push a feature branch, open a PR, have an independent subagent review the pushed diff adversarially, post its findings on the PR, and resolve feedback before merging through the PR. Open the PR without asking. Get explicit approval before pushing, posting review comments, or merging.
